## The product

**Windows Power Scripts Vol. 1** — $1.00

Ten battle-tested scripts (PowerShell 5.1 + Python 3.8+, Windows 10/11) that automate the
chores IT pros run by hand every week:

1. **disk-cleanup.ps1** — find (and remove) stale temp/cache files, see MB reclaimable
2. **bigfiles.ps1** — answers "why is my disk full?" in one command
3. **pc_report.ps1** — startup programs, top CPU/RAM hogs, disk free — one screen
4. **netinfo.ps1** — adapters, DNS, public IP, listening ports
5. **wifi_audit.ps1** — Wi-Fi profile audit and report export
6. **backup.ps1** — robocopy backups with automatic rotation (keep newest N)
7. **bulk_rename.py** — regex bulk rename with dry-run mode
8. **csv_dedupe.py** — de-duplicate CSV rows by any columns
9. **pdf_merge.py** — merge PDFs in order (dependency auto-installs)
10. **img_resize.py** — batch-resize photos (dependency auto-installs)

Plus: **password_gen.py** (secure passwords/passphrases) and **subnet_scan.py** (LAN device sweep).

No installs. No telemetry. No accounts. Everything runs locally.
